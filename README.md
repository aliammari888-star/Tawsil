# Tawsil (توصيل) — تطبيق إدارة وتوصيل الطلبات

تطبيق ويب حديث مبني بـ **React + TypeScript + Tailwind CSS** لإدارة وتوصيل الطلبات بثلاثة أدوار رئيسية، معاد كتابته بدقة من مشروع أندرويد الأصلي مع الحفاظ الكامل على كافة الميزات وقواعد العمل ومنطق الأدوار.

## 🚀 الأدوار وصلاحيات التطبيق
- **العميل (Client)**:
  - إنشاء طلبات توصيل جديدة (عنوان الاستلام، عنوان التوصيل، وصف الطلب، السعر بالدينار التونسي د.ت).
  - متابعة قائمة طلباته مع تفاصيل المسار والحالة وتحديثات الوقت الفعلي.
  - إمكانية إلغاء الطلب وهو في حالة الانتظار ("في الانتظار").
- **الموصل (Livreur)**:
  - استعراض كافة الطلبات المتاحة للقبول في الوقت الفعلي ("طلبات متاحة").
  - قبول الطلب وتعيينه لنفسه.
  - متابعة توصيلاته الجارية ("توصيلاتي") وتحديث حالة الطرد:
    - تم الاستلام ("تم الاستلام").
    - تم التوصيل بنجاح ("تم التوصيل ✅").
- **الأدمن (Admin)**:
  - لوحة تحكم شاملة تعرض إحصائيات النظام (إجمالي الطلبات وإجمالي المستخدمين).
  - استعراض كافة الطلبات مع إمكانية إلغاء أي طلب غير مكتمل.
  - استعراض قائمة كافة المستخدمين المسجلين مع أرقام هواتفهم وبريدهم وأدوارهم.

---

## 🎨 الهوية البصرية والتصميم
- تم الحفاظ على الألوان الأصلية للمشروع:
  - اللون الأساسي: الأزرق `#1E88E5`
  - اللون الثانوي/التحذيري: البرتقالي `#FFA000`
  - شارات الحالات:
    - في الانتظار: `#FFA000`
    - تم القبول: `#1E88E5`
    - تم الاستلام: `#8E24AA`
    - تم التوصيل: `#43A047`
    - ملغى: `#E53935`
- خط عربي واضح ومهيأ بالكامل للغة العربية واتجاه اليمين لليسار (`RTL`).
